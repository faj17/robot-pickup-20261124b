One original pickup line written for a robot to say out loud (97 characters):

> I scanned the whole room and my sensors kept returning one error: you were standing too far away.

The robot scans the room with its sensors — a machine act, not a human line with a beep pasted on. The turn is the error report: the only fault the sensors find is that the person is standing too far away, so the diagnostic becomes the flirt.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
